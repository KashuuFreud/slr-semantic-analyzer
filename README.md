# Compiler IR Generator

本仓库用于编译器设计专题实验六：中间代码生成。

实验六的核心目标是：在词法分析、语法分析和语义分析的基础上，将输入程序进一步翻译为中间代码表示。本项目采用四元式作为主要中间表示形式，并额外展示符号表、AST、IR 生成轨迹、优化后中间代码和伪汇编预览。

## Branches

本仓库目前保留两个分支，用于区分不同实验场景。

### `progress`：课程验收版本

`progress` 分支是本次实验六验收推荐使用的版本。

该版本针对课程 PPT 和示例 `.src` 文件的文法进行了适配，重点保证能够读取并分析课程提供的测试程序。它不是完整 C 语言编译器，而是面向实验六示例文法的小型中间代码生成器。

该版本支持：

- 导入 `.src` 测试文件；
- 函数定义后允许出现分号，例如 `};`；
- `return` 语句允许不写分号；
- 顶层函数调用允许不写分号，例如 `main()`；
- 函数形参支持分号分隔；
- 函数实参支持尾逗号；
- 支持变量声明、数组声明、数组元素访问和数组元素赋值；
- 支持 `print a` 和 `print(a)` 两种形式；
- 支持赋值语句、算术表达式、关系表达式、`if`、`while`、`return`、函数调用；
- 输出四元式中间代码；
- 输出符号表、AST、IR Generation Trace、优化后 IR 和伪汇编预览；
- 对未声明变量、未声明函数、重复声明、类型不匹配等问题给出诊断信息。
